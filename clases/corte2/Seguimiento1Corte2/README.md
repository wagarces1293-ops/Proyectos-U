Acorde a las instrucciones de la actividad de seguimiento: Debe incluir descripción del proyecto, instrucciones de instalación (npm install) y comandos de ejecución.

El siguiente proyecto incluye 4 ejercicios que anteriormente eran js y ahora se adaptaran ts:

Para la instalacion de npm, Primero se debe ingresar a la pagina oficial de bun: y se ejecutara un comando dependiendo de sistema operativo. En el caso de windows:

https://bun.com/docs/installation#windows

Ejecutar en el cmd: powershell -c "irm bun.sh/install.ps1|iex"

y luego en la posicion del archivo ejecutar: npx tsc --init --strict true
